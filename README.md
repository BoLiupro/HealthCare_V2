## Overview

**HealthCare V2 / 守护天使** is a team software project developed for **EE311** and a software innovation & entrepreneurship competition. The system follows a client–server architecture with a Java Spring Boot backend and an Android client based on MVVM.

## Team

Bo Liu, Sun Xun, Lin Wei, Wu Jingqiang, Han Derong, Li Yiyang, Su Rongzeng, and Lin Yanxu.

## Architecture

```text
Android Client (MVVM)
        ↓ REST / network communication
Spring Boot Backend
        ↓
Application services / persistence
```

## Tech Stack

- Java
- Spring Boot
- Android
- MVVM architecture

## Project Purpose

The project was created as a full-stack team exercise around a healthcare-oriented application scenario. It combines mobile UI development, backend service design, API integration, and collaborative software engineering.
